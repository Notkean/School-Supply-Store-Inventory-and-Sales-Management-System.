# School Supply Store Inventory and Sales Management System

## Deliverable 1 – Scoping and Wireframes

### Project Description

The School Supply Store Inventory and Sales Management System is a system designed to help manage school supplies, inventory, and sales records. It allows users to easily monitor available products, record sales, and view reports.

### Purpose

The purpose of this system is to make the management of school supplies easier, faster, and more organized. It reduces manual recording and helps prevent errors in inventory and sales records.

## Main Modules

### 1. Login
- User login
- Secure access
- User authentication

### 2. Dashboard
- View total products
- View available stocks
- View total sales
- View low-stock products

### 3. Inventory Management
- Add school supplies
- View school supplies
- Update product information
- Delete products
- Monitor stock levels

### 4. Sales Management
- Record sales
- Select products
- Enter quantity
- Calculate total amount
- View sales transactions

### 5. Reports
- Inventory report
- Sales report
- Low-stock report
- View transaction history

## User Stories

### Administrator

- As an administrator, I want to log in so that only authorized users can access the system.
- As an administrator, I want to add products so that new school supplies can be recorded.
- As an administrator, I want to update product information so that inventory records remain accurate.
- As an administrator, I want to delete products so that unavailable products can be removed.
- As an administrator, I want to view reports so that I can monitor inventory and sales.

### Store Staff

- As a store staff member, I want to view available products so that I can assist customers.
- As a store staff member, I want to record sales so that transactions are properly documented.
- As a store staff member, I want to check stock levels so that I know which products are available.

## Functional Requirements

1. The system shall allow authorized users to log in.
2. The system shall allow users to add school supplies.
3. The system shall allow users to view school supplies.
4. The system shall allow users to update product information.
5. The system shall allow users to delete products.
6. The system shall allow users to record sales transactions.
7. The system shall automatically calculate the total sales amount.
8. The system shall update inventory after a sale.
9. The system shall display low-stock products.
10. The system shall generate inventory and sales reports.

## Non-Functional Requirements

- The system should be easy to use.
- The system should provide accurate inventory and sales records.
- The system should respond quickly to user actions.
- The system should protect user information.
- The system should be reliable and organized.

## Scope

The system focuses on managing school supply inventory and sales transactions. It includes product management, stock monitoring, sales recording, and report generation.

## Limitations

- The system is intended for school supply store operations.
- It does not include online payment processing.
- It does not include online ordering or delivery.
- Reports depend on the accuracy of information entered by users.
