# School Supply Store Inventory and Sales Management System

## Project Backlog

### User Stories

| ID    | User Story                                                                                                                | Priority |
| ----- | ------------------------------------------------------------------------------------------------------------------------- | -------- |
| US-01 | As an administrator, I want to log in securely so that only authorized users can access the system.                       | High     |
| US-02 | As an administrator, I want to add school supplies so that new products can be recorded.                                  | High     |
| US-03 | As an administrator, I want to view school supplies so that I can monitor available products.                             | High     |
| US-04 | As an administrator, I want to update product information so that inventory records stay accurate.                        | High     |
| US-05 | As an administrator, I want to delete products so that unavailable products can be removed.                               | Medium   |
| US-06 | As a store staff member, I want to record sales so that transactions are properly documented.                             | High     |
| US-07 | As a store staff member, I want the system to calculate the total amount automatically so that sales recording is easier. | High     |
| US-08 | As a store staff member, I want inventory to update after every sale so that stock records remain accurate.               | High     |
| US-09 | As an administrator, I want to view low-stock products so that I know which supplies need restocking.                     | Medium   |
| US-10 | As an administrator, I want to generate inventory and sales reports so that I can monitor store performance.              | Medium   |
