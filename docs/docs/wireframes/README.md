# Wireframes

This folder contains the wireframes for the School Supply Store Inventory and Sales Management System.

## Purpose

The wireframes show the basic design and layout of the system before development. They help the team plan the screens and functions of the system.

## Wireframe Screens

The following screens are included:

1. Login Page
2. Dashboard
3. Product Management
4. Inventory Management
5. Sales Management
6. Sales Transaction
7. Reports
8. User Management

## Target Users

- **Administrator** – manages products, inventory, sales, reports, and users.
- **Store Staff** – manages products, inventory, and sales transactions.

The PNG or image files in this folder contain the actual wireframes of the system.

## Project

**School Supply Store Inventory and Sales Management System**

The system is designed to help manage school supply products, inventory records, and sales transactions in an organized way.
