# School Supply Store Inventory and Sales Management System

## Wireframes

This folder contains the wireframes for the School Supply Store Inventory and Sales Management System. The wireframes show the planned design and layout of the system before development.

## Wireframe Screens

### 1. Login Page

The login page allows authorized users to enter their username and password to access the system.

### 2. Dashboard

The dashboard provides an overview of the system, including total products, available stock, total sales, and low-stock products.

### 3. Inventory Page

The inventory page allows users to add, view, update, delete, and search school supply products. It also displays the available quantity of each product.

### 4. Sales Page

The sales page allows store staff to record customer purchases, select products, enter quantities, and calculate the total amount.

### 5. Reports Page

The reports page allows administrators to view inventory reports, sales reports, low-stock products, and transaction history.

## Purpose of the Wireframes

The wireframes serve as a guide for developing the system interface. They help the team visualize the layout, features, and navigation of each system screen before implementation.
