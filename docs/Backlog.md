# Backlog

## C1: Add new customer
- **Description**: As a user, I can register a new customer
- **Acceptance Criteria**:
  - Form validates required fields (name, contact)
  - System saves to database & shows success message
  - Duplicate customer cannot be added

## C2: View customer list
- **Description**: As a user, I can see all customers
- **Acceptance Criteria**:
  - List loads in under 2 seconds
  - Shows ID, name, contact, and total spent
  - Supports sorting & simple search

## I1: Add inventory item
- **Description**: As a user, I can add stock items
- **Acceptance Criteria**:
  - Prevents negative/zero quantity
  - Assigns unique SKU automatically
  - Updates stock count immediately after save
