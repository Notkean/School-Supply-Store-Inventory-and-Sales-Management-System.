# Deliverable 1 – Scoping and Wireframes

## Project Title

**School Supply Store Inventory and Sales Management System**

## Project Overview

The School Supply Store Inventory and Sales Management System is designed to help manage school supplies, inventory, and sales transactions. The system will make it easier to record products, monitor stock levels, manage sales, and generate reports.

## Project Objectives

1. To provide an organized way of managing school supply inventory.
2. To allow users to add, update, view, and delete products.
3. To record and manage sales transactions.
4. To automatically update inventory when products are sold.
5. To provide inventory and sales reports.
6. To help reduce errors caused by manual recording.

## Target Users

* **Administrator** – manages products, inventory, users, and reports.
* **Store Staff** – manages products and records sales transactions.

## Main Features

### Login

* Secure user login
* User authentication
* Logout

### Dashboard

* Total products
* Available stock
* Total sales
* Low-stock products

### Inventory Management

* Add product
* View products
* Update product information
* Delete products
* Search products
* Monitor stock quantity

### Sales Management

* Record sales
* Select products
* Enter quantity
* Calculate total amount
* Save transactions
* Automatically update inventory

### Reports

* Inventory report
* Sales report
* Low-stock report
* Sales transaction history

## Functional Requirements

1. The system shall allow authorized users to log in.
2. The system shall allow users to add school supplies.
3. The system shall allow users to view school supplies.
4. The system shall allow users to update product information.
5. The system shall allow users to delete products.
6. The system shall allow users to record sales transactions.
7. The system shall calculate the total sales amount.
8. The system shall update inventory after a sale.
9. The system shall display low-stock products.
10. The system shall generate inventory and sales reports.

## Non-Functional Requirements

* The system should be easy to use.
* The system should provide accurate records.
* The system should respond quickly.
* The system should protect user information.
* The system should be reliable and organized.

## Wireframes

The planned wireframe screens are:

1. Login Page
2. Dashboard
3. Inventory Page
4. Sales Page
5. Reports Page

## Scope

The project covers the management of school supply products, inventory, sales transactions, and basic reports. It is intended to help store administrators and staff organize daily store operations.

## Limitations

* The system does not include online payment processing.
* The system does not include online delivery services.
* The system depends on users entering accurate information.
* The system is focused on school supply store operations.
